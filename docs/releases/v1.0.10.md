# Adaptive Alarm v1.0.10

- Bound physical siren and light service requests to five seconds per request.
- Retry siren ON only after a definite preflight failure and while the alarm remains triggered; never replay ambiguous actuation.
- Preserve existing configuration, entity IDs, explicit opt-in, and startup safeguards.
- Automated tests cover preflight and ambiguous failures. Physical devices have not been tested in this review.
