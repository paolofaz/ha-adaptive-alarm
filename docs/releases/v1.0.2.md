# Adaptive Alarm v1.0.2 — release stabile

Adaptive Alarm è l'integrazione Home Assistant con protezione adattiva a contatti
obbligatori AND, gruppi alternativi OR e sensori opzionali Protetti/In attesa/Esclusi.

## Correzioni finali

- **Sirena Zigbee2MQTT `siren.*`:** quando una sessione `armed_away`
  viene ripristinata dopo un riavvio e un contatto protetto è già aperto,
  l'evento è trattato come un **nuovo allarme**: la sirena viene richiesta ON
  prima delle notifiche, solo se il comando fisico è stato abilitato.
- Un allarme che **era già `triggered`** prima del riavvio **non riaccende**
  automaticamente la sirena. Il timer hardware Zigbee resta la protezione
  contro una durata incontrollata.
- Rimossa l'ultima dicitura di anteprima dai metadati del sensore Ready.
- Scheda Lovelace `custom:adaptive-alarm-card` per le dashboard YAML
  esistenti: stato, contatti protetti/in attesa/esclusi, sirena e
  diagnostica Health con nomi dei sensori anomali.
- Test di regressione dedicati, incluso rendering JavaScript senza browser.

## Funzionalità confermate

- Pannello `alarm_control_panel` utilizzabile tramite HomeKit Bridge
- Notifiche per evento e destinatari condivisi
- Controlli di vibrazione per singolo sensore, preallarme e luci deterrenti
- Durata `triggered` configurabile e ritorno automatico ad `armed_away`
- Sirena reale **disabilitata per impostazione predefinita** e abilitabile
  esplicitamente soltanto dopo verifica dell'autospegnimento sul dispositivo
- Nessuna sirena fittizia e nessuna dashboard creata automaticamente

## Aggiornamento

Aggiornare l'integrazione tramite HACS, **senza eliminarla o ricrearla**,
riavviare Home Assistant e ricaricare la pagina Lovelace. La risorsa
JavaScript è versionata `v=1.0.2`.

Per una plancia YAML, dentro `cards:` inserire:

```yaml
- type: custom:adaptive-alarm-card
  title: Antifurto
```

La risorsa viene registrata automaticamente quando le risorse Lovelace
sono gestite in storage mode. In resource mode YAML, seguire il README
per la voce `lovelace.resources`.

**Prima di abilitare la sirena vera:** assicurarsi che il vecchio antifurto
YAML non la comandi più, verificare i servizi `siren.turn_on` e
`siren.turn_off`, l'autospegnimento Zigbee2MQTT e il disinserimento
durante `triggered`. I test automatici non sostituiscono questa prova.

Le automazioni di presenza, LED Shelly, fotografie Telegram, RF e script
iPhone rimangono esterne all'integrazione.
